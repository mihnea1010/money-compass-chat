# Remix of Finwise Chat And Compass

Fa-mi o aplicatie care ma ajuta la financiar advising ca parte a hackathonului asta. Am atasat si ideea mea. Vreau sa imi faci o aplicatie care dupaia poate fi portata eventual si pe web si pe telefon (gen react sau ce alteva crezi ca e mai potrivit). Construieste momentan doar ideea de baza: Pagina cu chatbotul (fa-o sa semene ca paginile ce llm-uri populare: simplu, intuitiv). A doua sa fie dashboardul. Dupa vom implementa noi alte feature-uri mai complexe
